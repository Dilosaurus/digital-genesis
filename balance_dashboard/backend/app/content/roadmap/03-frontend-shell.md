## frontend shell

Full rewrite of the dashboard frontend as a **gothic-tech codex**. Sacred machine horror aesthetic: Cinzel display serif, Cormorant Garamond body prose, JetBrains Mono for terminal voice. Warm void palette (`#0A0808` base with brown undertone, oxidized gold accents, blood-relic danger color).

Filesystem-style sidebar with filename navigation. Wordmark with 14s glitch animation. Scanlines on terminal surfaces, paper grain overlay on content surfaces, heavy vignette. No purple gradients. No Inter.

Vision homepage with roman-numeral gutter, marginalia sidebar, pull-quote blockquotes, three-pillar design philosophy statement.
