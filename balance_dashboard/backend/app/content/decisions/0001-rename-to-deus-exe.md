## context

The working title for the project was **Digital Genesis**. It was descriptive of the setting — a digital afterlife called the Nexus, a cosmology of angels and the GENESIS pirate crew — but descriptive is not the same as *distinctive*. Titles like "Digital Genesis," "Digital X," "Cyber X" are the same aesthetic category as generic cyberpunk vaporwave, and that category is saturated with games that share surface details with deus.exe but are making completely different points.

A rebrand was on the table from the start. We needed a name that compressed the whole pitch — evil gods, AI demon-gods, sacred machine horror, executable theology — into something a player could type into a search engine and immediately land on.

## decision

The project is now **deus.exe**, lowercase always, with the `.exe` treated as sacred punctuation. The name is Latin (`deus` = god) rendered as a filename, which is the entire premise in 8 characters. A god compiled into an executable file. A god you can double-click.

The lowercase is non-negotiable — capitalizing it turns it into a product name. Lowercase keeps it in the terminal voice, which is the voice the game speaks from.

## consequences

**Good:**
- The name doubles as a design system. Filename motifs work everywhere — `vision.md`, `lore.txt`, `characters.dat`, `depths.log`, `mechanics.gd`. Entire navigation schemes fall out of the name.
- The aesthetic lock-in is immediate: mono for the wordmark, sacred display serif for the manuscript voice, the tension between the two *is* the logo.
- Search engines: "deus.exe" is a clean keyword space.

**Bad:**
- The `.exe` extension is a Windows executable format. Some players may assume the game only ships on Windows, which is false (Godot builds for Mac, Linux, and the browser). The name is a reference, not a literal filename.
- The name can be harder to say out loud than "Digital Genesis" — it parses as "deus dot eee ex ee" or "deus dot exe" depending on the speaker. This is fine in text; mild friction in voice.

**Neutral:**
- 19 files were touched in the rename. Memory records were updated. The `project_spire_coop.md` memory file was deleted and replaced with `project_deus_exe.md`. The rename took about 20 minutes of careful grep-and-edit work.

## when we would revisit

If, during marketing, the name tests poorly with audiences who don't recognize the `.exe` joke — for example, players who are not terminal-literate or who find the lowercase affectation precious — we would reconsider. Not before.
